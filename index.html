Hoop Zoo is a basketball game for children. Animals play one-on-one, against the computer or against a friend on the same device.

This page explains, in plain language, what the game does — and doesn't do — with information.

The short version

  • We don't collect, store, sell or share any personal data: not from children, not from parents, not from anyone.
  • The game never goes online. There are no accounts, no servers and no internet connection.
  • There are no ads, no analytics, no tracking, no in-app purchases and no third-party SDKs.
  • Game progress is saved only on the device, and you can wipe it at any time.

What the game remembers

To pick up where the child left off, the game keeps a small save on the device itself. None of it is personal information, and none of it is ever sent anywhere.

InformationWhat it's for
Points and levelUnlocking new animals and ball designs as the child plays
The last animals picked, the ball design and the difficultyStarting the next match faster
Number of matches, wins, baskets and cups wonShowing the child's progress
Which hints, animal facts and new unlocks were already shown, and whether the practice was playedNot repeating them too often, and filling the fact album
Language, sound and left- or right-handed controlsKeeping the game the way you set it

The save lives in the app's own storage on the device. Like any app data, it may be included in your device's own backups (for example iCloud Backup), which Apple manages for you. It is not linked to any account, name, device identifier or advertising identifier.

Permissions

The game asks for no permissions: no camera, microphone, photos, contacts, location or notifications.

Internet and links

Hoop Zoo works fully offline and makes no network requests. The only link out of the game is this privacy policy. It sits in the For Parents area behind a parental gate (a multiplication question written out in words, answered on a number pad) and opens in the device's web browser.

This website is hosted by GitHub Pages, which may record standard request information, such as an IP address, under GitHub's Privacy Statement. The website itself has no analytics, cookies or tracking.

Analytics and advertising

There are none. No analytics, no crash reporting, no advertising, no trackers and no third-party code that collects anything. We don't build a profile of anyone, and the game never uses an advertising identifier. The game is built with open-source libraries that run entirely on the device.

Children's privacy

Hoop Zoo is made for children and follows the App Store's rules for the Kids category. It does not collect personal information from children. There is no chat, no sharing, no sign-in and no way for a child to send anything from the game. Everything meant for adults (this link, the open-source licence notices and the progress reset) is behind the parental gate.

Deleting the data

  • Reset progress: on the main menu tap Parents, answer the question, then tap Reset progress twice.
  • Remove everything: delete the app. Its saved data goes with it.

Since we never receive any data, there's nothing to delete on our side.

Your rights

Privacy laws such as the GDPR (EU) and KVKK (Türkiye) give you rights over personal data. Hoop Zoo holds no personal data, and the game's save stays on your device, so you can look at, reset or delete it yourself at any time, without asking anyone.

Changes to this policy

If this policy ever changes, we'll update the effective date above and publish the new version at this same address before it takes effect.
