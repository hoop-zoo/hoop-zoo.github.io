# Hoop Zoo — website

Public pages for the Hoop Zoo iOS game, served by GitHub Pages from the
`hoop-zoo` organisation, so no personal name is in the address:

- https://hoop-zoo.github.io/ — Privacy Policy (EN)
- https://hoop-zoo.github.io/gizlilik-politikasi/ — Gizlilik Politikası (TR)
- https://hoop-zoo.github.io/support/ — Help & Support (EN)
- https://hoop-zoo.github.io/destek/ — Yardım ve Destek (TR)

The game opens the policy from its parents area (`hoop-zoo/src/platform/links.ts`).
Static HTML and one stylesheet: no build step, no scripts, no web fonts, no trackers.
The favicons are the app icon, scaled with `sips`. Publishing: see `DEPLOY.md`.
